# ☕ Coffee Shop Sales Dashboard (Excel)

## Project Overview

This project analyzes coffee shop sales data using Microsoft Excel.

The dashboard provides interactive insights into:

- Total Sales
- Total Orders
- Average Bill
- Best Selling Products
- Sales by Month
- Sales by Category
- Sales by Location
- Customer Purchase Trends

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Conditional Formatting
